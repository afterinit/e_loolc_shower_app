# loolc 洗浴 · Android

> 湖北民族大学校园浴室洗澡码工具。

## 软件特色

- **打开即取码**　校园账号登录后直接进入洗澡码页面。浴室会话有效时，打开 App 会自动读取洗澡码。
- **倒计时与手动刷新**　显示洗澡码的生成时间和剩余有效期，到期后隐藏旧码。点击右上角的刷新图标可以重新取码。
- **洗澡码显隐**　洗澡码前五位默认显示为 `*`，点小眼睛展开，再点一次收起。每次刷新后恢复隐藏。
- **浅色和深色模式**　点击右上角的主题图标，以圆形动画切换配色。

## 快速开始

1. 在 Android 8.0 或更新版本的手机上安装 APK，然后打开 `loolc 洗浴`。
2. 输入湖北民族大学校园账号和密码，点击「登录并查看洗澡码」。
3. 在首页查看剩余有效期，点洗澡码右上角的小眼睛查看完整号码，右上角刷新按钮可刷新洗澡码。

## 注意事项

- **e民大登录状态**　首次登录和重新授权可能使 e民大 退出登录。已有浴室会话失效时，点击刷新图标并确认后才会重新登录校园账号。
- **取码依赖网络**　登录和取码需要连接校园认证与浴室服务。请求失败时，可根据页面提示检查网络或重试（必要时可检查VPN）。
- **登录信息保存在本机**　校园账号、密码和浴室会话使用 Android Keystore 加密保存。点击右上角的退出图标可清除本地登录信息。
